# 美式轮盘

本地单人美式轮盘。三十八格（0、00、1–36），深绿色赌桌，筹码只存在这台浏览器里。没有账号，不联网，也不涉及真钱。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。

```bash
npm test        # 赔率与对局状态
npm run build   # 类型检查并打包到 dist/
npm run preview # 预览打包结果，同样是 4317 端口
```

## 怎么玩

1. 选筹码（1 / 5 / 25 / 100 / 500），再点注区。同一格可以加注，筹码会叠起来。悬停可看赔率与已下金额。
2. 撤销去掉最后一笔，清空收回本局全部下注。余额不够时，底部状态栏会闪红字。
3. 至少下一注后点「开转」。结果在点击时已经决定，轮盘和白球只是把这个结果转出来。
4. 结算后桌上的筹码清掉，余额留下，可以继续下一局。

赔率是美式赌场赔率（净赢，本金另退）：

| 注 | 赔率 |
| --- | --- |
| 直注 | 35:1 |
| 红 / 黑、单 / 双、小（1–18）/ 大（19–36） | 1:1 |
| 打、列 | 2:1 |

0 和 00 通杀红黑、单双、大小、打和列。

## 存在本机

键名是 `american-roulette-v1`。每次结算、更改设置，以及离开页面时写入：

- 余额（开局 1,000，可在设置里确认后重置）
- 最近十次开奖
- 音效（默认关）和跳过动画

未开转的桌面注不会恢复；刷新后那些筹码退回余额。已经点了开转再刷新，则按已决定的结果结算。音效用浏览器合成，没有外部音频文件。
